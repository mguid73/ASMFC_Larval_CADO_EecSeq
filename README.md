# Delatte-Guidry et al. - Larval Oyster Cycling CADO (Coastal Acidification and low Dissolved Oxygen)
 
Data and reproducible code for a cycled multistressor experiment on multiple populations of larval eastern oysters. This study characterized the adaptive responses of larval oysters to diel cycling of simultaneous coastal stressors (pH and DO), and  how those responses differed across population.

> Status: Manuscript in preparation. This repository is under active development and will be finalized upon publication.
